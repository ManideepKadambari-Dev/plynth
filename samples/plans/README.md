# Sample plans

`apartment-01.png` is a 2400 x 1600 grayscale floor plan of a small apartment (three rooms plus an open living area). It was drawn by `samples/tools/make_sample_plans.py`, so it belongs to the project. Scale is 100 pixels per metre.

To regenerate it, run `python samples/tools/make_sample_plans.py` from the repository root. It needs only the Python standard library, and the output is the same bytes every run.
